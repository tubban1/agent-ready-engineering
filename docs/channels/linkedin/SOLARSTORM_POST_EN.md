# LinkedIn — ARE Solarstorm evidence-based post

A server may expose a perfectly readable MCP tool catalog while still leaving critical questions about real Agent reliability unanswered.

We tested a public, read-only space-weather MCP called Solarstorm using Agent-Ready Engineering (ARE), a World2-managed research service.

Here is what the evidence supports:

• All four discovered public tools were inspected and successfully called.
• A bounded MCP 2026 protocol probe passed nine checks with zero failures — not full official certification.
• A real Claude Code Agent completed one multi-tool user question, with an independent NOAA reference.
• The dated NOAA comparisons included two matches and one time-sensitive instantaneous X-ray reading difference.
• ARE's 39 engineering checks resulted in 4 PASS, 2 failures against ARE recommendations, 10 N/A and 23 NOT_VERIFIED.

We did not assign a maturity score. We also could not establish that public source version 1.0.3 corresponded to the live server's 1.0.0.

One subtle observation: an out-of-range latitude returned an error message with MCP isError=false, while an omitted required parameter returned isError=true. This is a potential error-contract improvement, not a claimed security vulnerability or official MCP protocol violation.
