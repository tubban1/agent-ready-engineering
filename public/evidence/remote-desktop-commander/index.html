Engineering review

What worked

  • OAuth-authenticated remote connector found a paired online macOS device.
  • File reads, directory listing, metadata, filename search and bounded non-mutating computation worked.
  • Real Agent correctly analyzed 24 synthetic CI records across eight services: four latest PASS, four latest FAIL, two slow runs and five services needing action.
  • An independent parser recomputed the same result and matched a pinned SHA-256 fixture.

Design improvement candidates

  • Stable structured error envelope on a nonexistent-file read (ENOENT).
  • Explicit truncation/cursor and optional field projection for large reads.
  • Progressive discovery to avoid presenting all 30 full schemas at once.
  • Visible idempotency keys, revision preconditions and dry-run options on mutable operations.

These are ARE design criteria, not proof of an official MCP MUST violation. No write or dangerous operation was performed.
