Agent-Ready Engineering — MCP endpoint

Public, read-only knowledge server for the Agent-Ready Engineering framework: documents, maturity checks, templates, evidence requests and workflow prompts.

ARE Benchmark — score your MCP → — value-first, evidence-scoped MCP preflight, creator claim, evidence submission and retest history. Not an official maturity certification.

Browse ARE project evaluations → — live evidence dashboard backed by Neon. Automated research is preliminary.

Endpoint (Streamable HTTP, no sign-in):

https://are.fde.fan/mcp

Example client configuration:

{
  "mcpServers": {
    "are": { "type": "http", "url": "https://are.fde.fan/mcp" }
  }
}

Checks of your own engagement workspace (validate deliverables, assess scenarios, aggregate a portfolio) are not available here so client files never leave your machine. Run the local server with --workspace for those.
