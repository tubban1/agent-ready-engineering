## 字段说明
| 字段 | 取值 |
| :--- | :--- |
| 类型 | `read` 只读查询 / `validate` 校验（dry-run）/ `draft` 草稿 / `commit` 正式提交 |
| 副作用 | `none` 无 / `internal-write` 内部写入 / `outbound` 对外发送 / `money` 涉及金钱 |
| 可撤销 | `yes` 是 / `compensable` 可补偿 / `irreversible` 不可逆 / `n/a` 无副作用 |
| 风险等级 | `low` 低 / `medium` 中 / `high` 高（决定授权矩阵中的级别） |
| 使用频率 | 代表任务中用到的次数或真实调用记录；没有数据写“未测” |
| 价值贡献 | 对价值卡片中哪个指标有贡献：高 / 中 / 低 |
| 改造成本 | 高 / 中 / 低（简述原因） |
| 现状问题 | 万能执行器 / 无幂等 / 无版本 / 错误不可判断 / 返回过大 / 无状态查询 等 |
| 决定 | `first-batch` 首批 / `waiting-pool` 待定池 / `not-exposed` 不开放给 Agent |
