## 筛选问题
| 代号 | 问题 | 取值 |
| :--- | :--- | :--- |
| N | 是否需要 Agent（模糊意图、多步规划、跨系统组合、情况差异大）？ | 是 / 否 / 不确定 |
| S | 是否有更简单的替代方案（固定脚本、规则引擎、普通集成、更好的 UI、现成工具）？ | 是（写明）/ 否 |
| R | 需求是否反复发生？ | 是 / 否 / 不确定 |
| V | 价值潜力 | 高 / 中 / 低 |
| K | 出错时的风险（金钱、对外发送、不可逆、数据泄露） | 高 / 中 / 低 |
| B | V 与 K 判断的依据 | 实测数据 / 文档 / 访谈 / 假设 |

> 这一阶段的 V 和 K 是判断，不是实测。必须记录依据（B）；依据为“假设”的判断，要在价值卡片中确认。
